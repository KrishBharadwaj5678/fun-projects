## <img src="https://github.com/KrishBharadwaj5678/fun-projects/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/fun-projects.git
````

### 2️⃣ Переход в репозиторий

```bash
cd fun-projects
```

### 3️⃣ Выбор папки проекта

Выберите любой проект из доступных папок в репозитории.

### 4️⃣ Открытие в браузере

Просто откройте файл `index.html` в браузере.
