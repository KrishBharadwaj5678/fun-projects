## <img src="https://github.com/KrishBharadwaj5678/fun-projects/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/fun-projects.git
````

### 2️⃣ リポジトリへ移動する

```bash
cd fun-projects
```

### 3️⃣ プロジェクトフォルダを選択する

リポジトリ内から、実行したいプロジェクトのフォルダを選択します。

### 4️⃣ ブラウザで開く

`index.html` をブラウザで開くだけで、プロジェクトを実行できます。
